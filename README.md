  ## OVERVIEW
  A secure and scalable Job Portal Backend Application built using Java, Spring Boot, Spring Security, Spring Data JPA, Hibernate,
  and PostgreSQL. The application provides RESTful APIs for managing job postings, searching jobs, and performing CRUD operations
  while following industry-standard layered architecture.

  ## Features
  Create, Update, Delete, and View Job Postings
  Search Jobs by Keywords
  RESTful API Development
  Spring Security Authentication
  PostgreSQL Database Integration
  AOP-Based Logging and Performance Monitoring
  Layered Architecture (Controller-Service-Repository)
  Exception Handling and Validation

  ## Tech Stack
   Java
   Spring Boot
   Spring Security
   Spring Data JPA
   Hibernate
   PostgreSQL
   Maven
   REST APIs
   AOP
